# Madhav Ecommerce Sales Dashboard (Power BI)

## Project Overview
This project presents an interactive Power BI dashboard built to analyze ecommerce sales data for Madhav Store across India. The dashboard helps track key sales metrics, profitability trends, customer behavior, and category-wise performance using interactive visuals and filters.

A custom dark gradient background is used to enhance the dashboard’s visual appeal and readability.

---

## Objective
To design a centralized and interactive Power BI dashboard that enables effective analysis of online sales performance and supports data-driven decision making.

---

## Data Sources
The project uses two CSV files:

- Orders.csv  
  Contains order-level transactional data such as order date, state, customer name, payment mode, quantity, and sales amount.

- Details.csv  
  Contains product-related details including category, sub-category, and profit information.

The datasets are imported into Power BI and connected using basic data modeling techniques.

---

## Dashboard Design
- Custom dark gradient background image for improved visual consistency  
- Clean and structured layout with KPI cards, charts, and slicers  
- User-friendly design focused on clarity and readability  

---

## Visuals and Components Used

### KPI Cards
- Total Sales Amount  
- Total Quantity Sold  
- Total Profit  
- Average Order Value  

### Charts
- Stacked Column Chart – Monthly profit analysis  
- Stacked Bar Chart – Profit by sub-category and sales by state  
- Donut Charts –  
  - Quantity by product category  
  - Payment mode distribution  

### Filters and Interactivity
- Button Slicer – Quarter-wise filtering (Qtr 1 to Qtr 4)  
- Dropdown Slicer – State-wise filtering  

---

## Key Insights Enabled
- Identification of high and low profit months  
- Analysis of top-performing states and sub-categories  
- Understanding customer contribution and purchasing behavior  
- Distribution of payment modes across orders
